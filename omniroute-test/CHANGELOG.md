# Changelog

## 0.2.0

- Initial release as a Home Assistant addon (test/pre-release)
- OmniRoute v3.8.50 (tag) — 350+ providers, 1200+ models, auto-fallback routing
- Bundled Redis for rate limiter and shared cache
- Ingress support (HA sidebar access)
- Minimal config surface: initial_password, require_api_key, auth_cookie_secure
- Based on official pre-built OmniRoute image (diegosouzapw/omniroute:latest)
